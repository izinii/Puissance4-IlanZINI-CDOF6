# Puissance 4 - TD1 Decentralization Technologies

Bienvenue sur le projet **Puissance 4** ! Ce projet a été développé dans le cadre du TD1 pour la matière *Decentralization Technologies*. L'objectif principal était de coder un jeu de Puissance 4 fonctionnel et interactif.

## Description du projet

Le jeu **Puissance 4** est un jeu classique où deux joueurs s'affrontent en déposant tour à tour des jetons dans une grille. Le but est d'aligner 4 jetons horizontalement, verticalement ou en diagonale avant son adversaire.

## Fonctionnalités

- Gestion complète du jeu de Puissance 4 :
    - Placement des jetons dans une grille.
    - Détection de la condition de victoire ou de match nul.
- Interface et logique adaptées pour une expérience intuitive.
- Respect des règles classiques de Puissance 4.
